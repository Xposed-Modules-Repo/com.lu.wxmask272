# Inkhide / 微信密友模块

[![LSPosed](https://img.shields.io/badge/LSPosed-supported-green)](https://modules.lsposed.org/)
[![Android](https://img.shields.io/badge/Android-8.0+-blue)](https://www.android.com/)
[![Telegram](https://img.shields.io/badge/Telegram-Channel-blue.svg)](https://t.me/MaskWechat3)

这是一个 免费的**微信 Xposed / LSPosed 模块**，用于保护隐私，将指定联系人设置为“密友”，并在微信各处隐藏其存在。

---

## 📲 使用方法

1. 安装本模块  
2. 在 **LSPosed / Xposed** 中勾选 **微信**
3. 重启手机或重启微信
4. 打开微信 → **我 → 设置 → 更多 → 关怀模式**
5. 长按「开启」即可进入密友管理界面
6. **搜索框输入：#hide**也可进入密友管理界面

## 📲 使用说明

在使用 InkHide 前，请仔细阅读以下配置指南，以确保隐私功能按预期工作。

### 1. 基础设置与名单管理
在使用任何隐藏功能前，您需要先设定好“密友”名单以及快捷操作方式。

- **名单管理**：
- 点击进入模块主页的“名单管理”，添加您希望隐藏的联系人（目前支持管理多人）。
- 也可通过“名单管理”点击密友直接进入聊天窗口

- **临时解除机制**：
    - **快捷显示**：开启后，在微信主界面**点击顶部标题**或**长按**（默认 1500ms）即可临时显示被隐藏的密友。
    - **解除密码**：为了防止误触或被他人破解，您可以设置一个数字密码（如 `123456`）。如果留空，则不需要密码直接解除。

- **快捷口令**：支持在聊天输入框通过特定指令快速将当前聊天对象加入/移出名单：
  ```text
  #add  -> 添加当前聊天对象到密友列表
  #del  -> 将当前聊天对象移除密友列表

### 2. 密友核心隐藏 (深度隐身)
| 功能选项 | 作用说明 | 推荐设置 |
| :--- | :--- | :---: |
| 隐藏密友 | 在主界面的“会话列表”中彻底不显示该好友的聊天框。 | ✅ 开启 |
| 隐藏通讯录好友 | 在“通讯录”列表中隐藏该联系人，防止翻找时暴露。（关闭后仅会话列表隐藏好友，通讯录不会隐藏也无法进入好友资料页）| ✅ 开启 |
| 隐藏聊天记录 | 点进聊天窗口后，历史消息自动隐藏。<br>技巧：连续点击屏幕3次可临时查看内容（自定义设置点击次数）。 | ⚠️ 按需开启 |
| 存储空间隐藏 | 在微信“设置-通用-存储空间”中，隐藏与该好友的聊天数据占用，防止通过清理缓存时发现端倪。 | ⚠️ 按需开启 |
| 隐藏语音/视频通话 | 当密友打来语音或视频电话时，直接拦截弹窗和响铃，就像没收到一样。 | ✅ 开启 |

### 3. 搜索隐藏
防止通过微信的“搜索”功能搜到敏感内容。
主页搜索隐藏：在微信首页顶部的搜索栏搜索关键词时，不会匹配到密友的昵称或聊天记录。
单聊搜索隐藏：在与密友的聊天窗口内点击右上角 ... -> 查找聊天记录 时，无法搜索到相关内容。

### 4. 消息提醒定制
解决“不想让别人看到通知，但自己又怕错过”的矛盾。
隐藏消息角标：
关闭微信图标右上角的红色数字。
关闭聊天列表顶部的“微信 x条”未读提示。
密友专属提醒（防漏看）：
震动：密友发消息时，手机会触发特定的轻微震动。
顶部加粗：微信顶部的标题栏文字会加粗显示，提示你有新消息，但不显示具体内容。

### 5. 实验室 (进阶功能)
包含一些实验性的增强功能。
防撤回：开启后，对方发送并撤回的消息，您将依然可以看到，并且会在聊天界面显示一条本地提示（例如：“对方撤回了一条消息”）。
阻止微信热更新：开启后可防止微信热更新导致模块突然失效。
自定义好友头像：配置后可以自定义好友头像（仅限自己本地可见）

### ❓ 常见问题 (FAQ)
Q: 开启“隐藏聊天记录”后，我怎么查看历史消息？

A: 进入聊天页面后，快速连续点击屏幕中间区域 3次，历史记录会短暂显示约 1500毫秒，请抓紧时间查看。

Q: 为什么设置了隐藏，重启手机后失效了？

A: 请检查您的 Xposed/LSPosed 框架是否正常运行，并确保 InkHide 模块已勾选并重启了微信作用域。
